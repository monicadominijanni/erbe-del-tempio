# Erbe del Tempio – sito statico

Sito HTML/CSS semplice, pronto per GitHub Pages.

## Pubblicare su GitHub Pages
1. Crea un repository pubblico su GitHub (es. `erbe-del-tempio`).
2. Carica i file (index.html, style.css, cartella images/, pagine legali).
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, cartella `/ (root)`.
4. Il sito sarà su `https://TUO-UTENTE.github.io/erbe-del-tempio/`.

## Aggiungere un'erba
Copia un blocco `<article class="card">` in index.html, cambia immagine, nome, descrizione, prezzo e link di affiliazione.

## Da completare
- Immagini in images/
- Link di affiliazione reali
- Pagine privacy.html, cookie.html, affiliazione.html
- Testo "Chi siamo"
